# Changelog

## 0.3.0

First public Kalypt codebase.

- Local-first scanner for files, directories, archives, documents, media, and source repositories
- JPEG/PNG, Office Open XML, PDF surface, MP3/WAV, MP4/MOV, ZIP, text, generic, secret, and Git inspection
- Safe clean-copy support for JPEG, PNG, DOCX, XLSX, PPTX, MP3, and WAV
- Recursive nested ZIP inspection with safety limits
- Bounded Git-history secret scanning
- `public`, `source-release`, `job-application`, and `photo-share` policy profiles
- Portable baselines and severity-based CI gating
- Text, JSON, Markdown, HTML, and SARIF reports
- Local drag-and-drop UI
- Git pre-push hook, composite GitHub Action, and explicit plugin API
